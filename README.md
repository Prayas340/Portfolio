# Prayas Dey // Developer Portfolio

> Motion-forward agency style single-page developer portfolio built with React 18, Vite, Framer Motion, and Tailwind CSS. Inspired by high-voltage cyber aesthetics and modern kinetic craft.

![Portfolio Preview](/public/assets/prayas-portrait.jpg)

## ⚡ Key Highlights & Features

- **Glitch-Tech Preloader**: Cinematic RGB chromatic-aberration split text decode animation on load.
- **Hero & Blended Identity**: Seamless background portrait blending, cyber scanline sweeps, and dynamic audio-reactive feedback via Web Audio API.
- **Left-to-Right Running Marquee**: Smooth infinite tech stack ticker featuring React, Next.js, TypeScript, Python, TailwindCSS, MongoDB, Firebase, Framer Motion, and more.
- **Curtis Designr-Inspired Selected Work Gallery**:
  - Horizontal sticky scroll deck with pinned 100vh viewport lock.
  - High-voltage neon green (`#8fd92f`) theme with deep electric purple typography.
  - 6 Production Project Showcases with custom interactive UI mockups (`Sahara`, `JanSetu AI`, `Mac OS Portfolio`, `Career Forge AI`, `YouTube Copilot`, `Personal AI Journal`).
  - **Pixel Construction Reveal Animation**: 8-bit digital pixel tiles that dissolve upon entering the screen to reveal project interfaces.
- **Pixel Mosaic Blend-Out Transition**: High-performance GPU HTML5 Canvas mosaic dissolve bridging the green projects track into the cyber dark void.
- **Philosophy & About Deck**: Embedded within the horizontal sequence, featuring core engineering principles, responsive mobile center-lock, and academic metadata (`RCCIIT Kolkata · BTech CSE`).
- **Experience & Ventures**: Official **GeeksforGeeks Campus Mantri (Student Ambassador)** apprenticeship spotlight with branded vector badge.
- **Integrated CV / Resume**: Instant PDF download & preview via `/SWE_Resume_Template.pdf`.
- **Navigation & Audio**: Fullscreen cyber matrix navigation drawer, sound FX toggle, and responsive custom cursor.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Animation**: [Framer Motion](https://www.framer-motion.com/) + [Lenis Smooth Scroll](https://lenis.darkroom.engineering/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) + Custom Cyberpunk CSS Utilities
- **Icons**: [Lucide React](https://lucide.dev/) + Custom Brand SVGs
- **Audio**: Native Web Audio API Sound Synthesizer

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or newer recommended)
- npm or yarn / pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Prayas340/Portfolio.git

# Navigate into project directory
cd Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
